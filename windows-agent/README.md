# Smart.z Windows Agent (`Smart.z-computer-pairing/windows-agent`)

أداة Windows الرسمية الآمنة لربط حاسوبك بتطبيق **Smart.z** وتنفيذ المهام المعتمدة (ملفات فقط).

---

## 🛠️ المميزات والضمانات الأمنية
1. **تشفير محلي متطور (AES-256-GCM + Ed25519)**: مفتاح الجهاز الخاص (`Ed25519`) يُولد محلياً ويحفظ مشفراً محلياً في `agent-identity.enc` (مربوط ببصمة جهاز Windows) ولا يغادر حاسوبك أبدًا.
2. **رمز الاستجابة السريعة (Terminal QR)**: عرض QR Code مباشر في نافذة الطرفية لسهولة المسح الفوري من تطبيق الهاتف.
3. **أدوات التثبيت والتشغيل الفوري**: ملفات دفعة (`install.bat`, `keygen.bat`, `pair.bat`, `start-agent.bat`, `test.bat`) لتشغيل الأداة بنقرة مزدوجة دون الحاجة لكتابة أوامر npm يدوياً.
4. **صلاحيات مقيدة (Sandbox)**: تنفيذ المهام مقتصر على مجلدات محددة يختارها المستخدم (`authorizedRoot`). لا يمكن الوصول لأي ملف خارج المجلد (تم اختبار منع اجتياز المسارات Path Traversal بنجاح).
5. **توقيع الطلبات (Ed25519)**: كل طلب إرسال واستقبال مُمضى وممحو النونْس (Nonce) لمنع هجمات إعادة التشغيل (Replay Attacks).

---

## 🚀 دليل التشغيل السريع للمستخدم العادي

### 1. التثبيت
انقر نقراً مزدوجاً على **`install.bat`** (لتثبيت الاعتمادات تلقائياً).

### 2. توليد المفاتيح
انقر نقراً مزدوجاً على **`keygen.bat`**.

### 3. ربط الجهاز عبر QR Code
انقر نقراً مزدوجاً على **`pair.bat`**. امسح رمز الاستجابة السريعة (QR) الظاهر في الشاشة بتطبيق Smart.z على هاتفك.

### 4. تشغيل الوكيل
انقر نقراً مزدوجاً على **`start-agent.bat`**.

### 5. تشغيل الاختبارات
انقر نقراً مزدوجاً على **`test.bat`** (تتحقق من 18 اختبار وحدة وتؤكد سلامة التشفير والصناديق الأمنية بنجاح 100%).
